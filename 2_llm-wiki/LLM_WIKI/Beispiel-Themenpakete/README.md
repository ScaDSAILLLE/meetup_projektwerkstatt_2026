# Beispiel-Themenpakete

Du willst ein **eigenes** LLM-Wiki bauen (siehe [[Track A - Baue dein Wiki/Leitfaden|Track A, Schritt 6]])? Nimm eines dieser Pakete als Rohmaterial: Dokumente in den `raw/`-Ordner deines Wikis kopieren und den Agenten ingesten lassen. Als `AGENTS.md` für dein Wiki nimmst du die [[Schema-Vorlage]].

Hinweis: Track A ist bereits ein fertiges Wiki zur Marsmission (mit erweiterten Quellen). Für ein eigenes Wiki ist darum das **Fiktive Startup** oder ein ganz eigenes Thema am spannendsten.

Fertig ausgearbeitet:

- [[Fiktives Startup/Übersicht|Fiktives Startup]] – 8 Dokumente über ein kleines Startup
- [[Marsmission/Übersicht|Marsmission]] – 5 Dokumente über eine fiktive Marsmission

Weitere Ideen zum Selbstbauen (falls jemand lieber von Null startet):

- Kochbuch / Rezeptesammlung
- Fantasy-Welt
- Festivalorganisation
- Detektivakte
- Büro-Survival-Guide
